# Learning Git & GitHub

Repository ini merupakan dokumentasi perjalanan belajar saya dalam memahami Git dan GitHub sebagai dasar penggunaan Version Control System (VCS) dalam pengembangan perangkat lunak.

Melalui repository ini, saya mempelajari konsep dasar Git, pengelolaan perubahan kode, penggunaan branch, kolaborasi melalui GitHub, hingga pengelolaan versi menggunakan tag dan release.
